# TacticalRMM-ChgHost
Change host/domain name of Tactical RMM server

# Prerequisites
- Register Domain name
- Add {api, mesh, rmm} A Records
- Obtain and Install SSL Cert for new Domain

# Setup & Run
curl -L -O https://raw.githubusercontent.com/smileymattj/TacticalRMM-ChgHost/refs/heads/main/chghost.sh

chmod +x chghost.sh

./chghost.sh
